# Changelog

Notable changes follow Keep a Changelog categories and Semantic Versioning after the version line is approved.

## Unreleased

### Added

- Framework-independent AFRICANIES package set covering models, storage, core services, theme, icons, custom elements, and the umbrella SDK bundle.
- Browser distribution outputs, npm/CDN usage examples, parity artefacts, and release-readiness verification assets for all seven publishable packages.
- Playground routes and interaction coverage for shell, actions, feedback, forms, overlays, tables, navigation, and SDK reference pages.

### Changed

- Audited Phase 1-9 parity status across models, storage, HTTP/query utilities, theme, icons, UI actions, UI feedback, forms, overlays, navigation/data, and npm/CDN packaging.
- Updated package manifests with explicit `main`, `types`, export-map, and published-file metadata for release verification.
- Refreshed README and `docs/` guidance to match the current SDK entry points, custom-element registration options, overlay naming, and release workflow.

### Fixed

- Restored action-menu parity for richer item metadata, disabled semantics, menu labelling, separator rendering, and href generation from routed items.
- Restored alert and toast icon rendering defaults and chip variant support to match the Angular behavioural contract more closely.
- Corrected stale documentation examples and parity matrices for completed shell, feedback, overlay, toast, and SDK verification work.
